archplan

Plan an architecture change, then let an agent build it. The as-is model comes from the code. You edit the to-be model. The difference becomes a plan.

Start here

  1. Look around. Pick a view: Components (packages and their dependencies), Types, Sequence (call flows) or Glossary (the terms each component owns). Type in Focus component… to zoom in on one part. Double-click a box to focus on it.
  2. Say what you want. Open the Plan tab and write the intent: what should this change achieve?
  3. Edit the to-be model. Select an item and change it in the Inspect tab: move a type, rename, forbid a dependency. Drag the blue dot from one box to another to connect them; select a line and press Delete to remove it. Diff shows what you changed.
  4. Comment. Select an item and write in Comments. Shift-click several items to comment on them together, for example an import cycle.
  5. Hand over. The Plan tab lists the tasks. Give it to the agent, or let the agent read it directly (below).

Working with Claude

In Claude Code, with the archplan plugin, type /archplan in the repository. Claude sees your comments as you write them and answers in the same thread. An orange decision thread waits for your choice; a feedback thread only needs reading. Claude can propose model changes (you see them in Diff; Undo reverts them). After it changes the code, the model reloads and the plan shrinks.

Keys

Shift-drag connects, Shift-click selects several, Delete removes the selection, ⌘Z undoes, Esc deselects, ? opens this help.

Everything is saved in .archplan/ in the repository. Commit it to share the plan and the threads.

Drag the blue dot on a box to another box to connect them. Select a line and press Delete to disconnect. In Sequence, drag from one lifeline to another to add a call, and drag a call up or down to reorder. The plan updates live.
